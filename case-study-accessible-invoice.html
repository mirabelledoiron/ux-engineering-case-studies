Accessible invoice data, from Outlook to mobile.

A brittle email table became one reusable contract across Outlook, mobile, and assistive technology.

Role
Design + implementation
Scope
Email, responsive, a11y
Result
High-adoption system pattern

01 · Problem

The table stopped making sense when it stacked.

Mobile stacking broke campaign, job, and price relationships.

02 · Constraints

Email clients changed the design space.

  • Outlook’s Word renderer
  • Limited mobile CSS
  • Duplicated markup, one meaning

03 · API / Contract

One relationship. Two renderings.

Jobs retain campaign, label, and price across both renderings.

Desktop + Outlook Shared headers

Mobile Repeated context

Responsive rule desktop by default → hide mobile from MSO → reveal mobile at ≤600px

04 · Accessibility

Context travels with the value.

One invariant guides every implementation.

  • Logical source and reading order
  • Job and price remain one item
  • Mobile labels restore context

05 · Validation

Test the relationship, not only the render.

  • Desktop + Outlook-safe markup
  • Mobile context and visibility rules
  • Assistive reading order

06 · Impact

A hard edge case became a trusted system capability.

The pattern became a high-adoption component.

Takeaway: I turned client constraints into a reusable contract.
