Documentation that behaves like product infrastructure.

Scattered knowledge became a shared component contract for people and AI-assisted workflows.

01 · Problem

The system lived in people, not in the product.

Fragmented guidance created repeated questions and inconsistent implementation.

02 · Constraints

One source had to serve multiple disciplines.

  • Design + engineering utility
  • Stable through API change
  • Human + AI retrieval

  • Keyboard + focus
  • Loading + recovery
